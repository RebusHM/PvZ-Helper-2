# 🌸 PvZ Helper 2 (@HelperPvZ2bot)

Telegram-бот помощник по франшизе **Plants vs. Zombies (PvZ 2 & PvZ 3)**, написанный на библиотеке `python-telegram-bot` (v20+ с `JobQueue` и `asyncio`).

---

## 🚀 Основной функционал

### 1. 📢 Автоматический трекер обновлений Google Play
* Фоновый мониторинг состояния **Plants vs. Zombies 2** (`com.ea.game.pvz2_row`, `com.ea.game.pvz2_na`) и **Plants vs. Zombies 3** (`com.ea.gp.pvzn3xt`).
* Опрашивает Google Play Store каждые 10 минут (настраивается).
* При обнаружении новой версии автоматически публикует пост в канал **[@NewsForPvZ](https://t.me/NewsForPvZ)** с сохранением версий в `data/versions.json` (исключает повторный спам).
* **Формат поста в канале:**
  ```text
  🌸 Новости франшизы PvZ 🍀
  🎮 Вышло обновление Plants vs. Zombies 2!

  Новая версия: 13.5.1

  Что нового:
  [Подробный список изменений напрямую от EA]
  ```
  С инлайн-кнопками:
  * `[ Официальная ссылка ↗ ]` (Google Play)
  * `[ Наш канал ↗ ]` (@NewsForPvZ)

### 2. ⚡ Мгновенная отдача через Telegram `file_id` (Кэширование)
* При первой выгрузке новой версии бот скачивает файл и отправляет его в Telegram.
* После успешной отправки бот сохраняет `file_id` документа в базу `data/file_cache.json`.
* **Все последующие запросы отдаются за 0.2–0.5 секунды** без повторного скачивания с интернета и без нагрузки на сервер!

### 3. 📊 Живой прогресс-бар в чате
* Во время скачивания файла с Google Play бот динамически обновляет статус в сообщении:
  ```text
  🎮 Plants vs. Zombies 2 • v13.5.1

  📥 Выкачивание из Google Play:
  [▰▰▰▰▰▰▱▱▱▱] 60% • 37.6 / 62.7 МБ
  ⚡ Скорость: 8.4 МБ/с • ⏳ Осталось: ~3 сек
  ```

### 4. 🔄 Авторестарт и бесперебойная работа 24/7 (Daemon)
* **На Windows**: запускайте файл `run_bot.bat` — при любом непредвиденном сбое или вылете бот автоматически перезапустится через 3 секунды.
* **На Linux VPS (systemd)**: готовый файл службы `pvzbot.service` и скрипт установки в 1 команду:
  ```bash
  sudo bash setup_systemd.sh
  ```
* **Docker / Docker Compose**: для изоляции в контейнере с флагом `restart: always`:
  ```bash
  docker compose up -d
  ```

## 🛠 Запуск

### На Windows:
Дважды кликните по файлу `run_bot.bat` в папке проекта.

### Напрямую через Python:
```powershell
python main.py
```
